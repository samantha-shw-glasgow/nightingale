# nightingale

## Mission

-   The goal of nightingale is to serve as a practical example to help you learn and try out practices of research software engineering.

## About

An exemplary R package for learning and trying out practices of research software engineering.

Nightingale contains:

-   **mortality.R** A dataset containing mortality data from the Crimean War, famously visualized by Florence Nightingale. The data shows the number of deaths from various causes.

-   **show_barplot.R** A function to create a bar plot visualisation of the mortality data.

-   **show_shiny_app.R** A function that launches a shiny dashboard that displays the bar plot of the mortality data.
